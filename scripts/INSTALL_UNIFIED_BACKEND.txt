RU Asset View — unified backend installation
================================================
Existing Apps Script project:
https://script.google.com/home/projects/1DphcKJivb6tw2HW9Bh7njUQ9SigNR8LsLv00jv0wJH-Ev_DHTyivBKJo/edit

Do not run setup() or resetToken(); preserve existing Script Properties and TOKEN.
Do not replace existing Code.gs; keep legacy assign/history routes.

1. Add a new script file in the SAME Apps Script project, named RUAssetHub.gs.
2. Paste the complete contents of scripts/ru-asset-hub-addon.gs into it.
3. In existing Code.gs, inside handle_(b), AFTER the bad-token validation,
   replace the old getAssets route and add these routes:

   if (b.action === 'getAssets') return ruGetAssets_(b);
   if (b.action === 'applyAssetChanges') return ruApplyAssetChanges_(b);
   if (b.action === 'photoPut') return ruPutPhoto_(b);
   if (b.action === 'photoGet') return ruGetPhoto_(b);

   Existing updateAssetNo/getAll/upsertMany routes can stay.
   Do not leave the old getAssets route above the new route.

4. Save, Deploy > Manage deployments > Edit > New version > Deploy.
   Keep the same deployment URL, Execute as Me, and configured access.
5. Open assign.html and use its manual 'Pull latest RU Asset DB' control.
   Then approve one existing pending edit and verify the exact key in
   RU Asset DB > assets. No token changes are necessary.

The site has already been published. Backend deployment is separate and
not performed by publishing GitHub code.
Never paste TOKEN into public repository files.
